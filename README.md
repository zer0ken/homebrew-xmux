# Homebrew tap

Homebrew formula for [xmux](https://github.com/zer0ken/xmux), a
cross-environment tmux/psmux session switcher.

## Install

```sh
brew install zer0ken/xmux/xmux
```

A tap is fetched automatically when the command names it. The formula installs
the prebuilt macOS binary for both Apple Silicon (`aarch64`) and Intel
(`x86_64`).

## Files

- `Formula/xmux.rb` — the formula, pointing at the xmux release binaries.
